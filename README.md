## 🌟 项目简介

**Market Replay（人人复盘）** 是一个面向投资爱好者、金融学习者与开发者的纯前端行情决策复盘仿真系统。

项目彻底摆脱了传统“只看后视镜静态图表”的学习方式，将真实历史日 K 线、当时发生的真实新闻事件、宏观背景与情绪切片结合，允许玩家在任意时间节点进行买入、卖出、做空或平仓，实时检验自己的投资逻辑与抗压能力。

本项目将**全部基础框架**与 **73 个精选免费复盘案例**完整开源。

## 📚 73 个开源复盘案例一览

### 1. 投资大师战役（经典决策）
* **奥马哈来信 · 华盛顿邮报 1973**：巴菲特逆向投资的经典一役。在石油危机与水门事件的暴跌中，以四分之一的内在价值建仓华邮，先承受 25% 浮亏的考验。
* **暗夜独行 · 网易 2002**：段永平逆向重仓。互联网泡沫破裂后，在 0.95 美元的退市边缘看清“现金比市值还多”的商业本质。

### 2. 市场风暴与世纪泡沫
* **5178 · 股灾十一周年祭（2015 · 中国A股）**：管理 3 亿资金，亲历从杠杆狂热、千股跌停到国家队救市的惊魂夏天。
* **对的太早 · 纳斯达克 2000（1999-2000 · 华尔街）**：看空科技泡沫却面临做空被轧、客户赎回的极限心理压力。
* **泡沫之巅 · 日本 1989（1986-1992 · 东京）**：重回日经指数冲刺 39000、“卖掉东京买下美国”的疯狂时代。
* **6124 · 全民疯牛 2007（2006-2008 · 中国A股）**：股改红利引爆的全民狂欢，亲历上证 6124 顶点与随后的去杠杆出清。

### 3. A股 24 年全景复盘（2002 - 2025 年）
* 包含 **2002 年至 2025 年** 连续 24 年的 A 股大盘行情与行业轮动数据：
  * 2003 “五朵金花”、2005 股权分置改革 998 见底、2007 历史大顶 6124
  * 2008 四万亿刺激前夕、2013 钱荒与创业板牛市、2014 券商启动牛
  * 2016 熔断、2017 漂亮 50、2019 核心资产抱团、2020 疫情宽松结构牛
  * 2021 新能源赛道顶、2024 冰点到沸点、2025 最新行情全景……

### 4. 美股 27 年全景复盘（1999 - 2025 年）
* 包含 **1999 年至 2025 年** 标普 500 与全行业轮动历史行情：
  * 1999 互联网狂热、2000 泡沫破裂、2001 911 冲击
  * 2008 次贷危机、2011 欧债风波、2020 熔断与放水大反弹
  * 2022 加息熊市、2023-2024 AI 科技巨头狂飙……

### 5. 国内商品期货 16 年全景复盘（2010 - 2025 年）
* 包含 **2010 年至 2025 年** 国内商品期货大宗多空轮动：
  * 黑色系（螺纹钢、铁矿石、焦炭）供给侧改革暴涨暴跌
  * 农产品（棉花天道、红枣、苹果霜冻、豆粕生猪周期）
  * 能源与贵金属（负油价奇观、伦敦镍逼空、黄金超级大牛市）

### 6. 蒙眼实战盲盘（Blind Test）
* 内置 60+ 个随机抽取、完全隐去名称代码的历史行情片段。纯凭宏观/产业/情绪简报与 K 线形态做出多空判断，结束后揭晓真实标的与大师当年的实际操作。

## 🛠 技术特性与架构

1. **纯前端运行，零构建依赖**：基于原生 HTML5 + Canvas Graphics 自绘 K 线组件，无需 Node.js 打包编译，双击即可本地运行。
2. **完整回放仿真引擎**：
   * `js/chart.js`：轻量级自绘交互 K 线图，支持光标悬停、十字线吸附、缩放平移。
   * `js/engine.js`：交易决策引擎，支持现金流记账、多空双向开平仓、浮动盈亏计算、最大回撤追踪与人格画像打分。
   * `js/ui.js` / `js/main.js`：剧本大厅与场景叙事控制器。
3. **数据解耦与高度可扩展**：所有案例统一为标准 JSON 格式（`cases/<case_id>/case.json`），只需按照格式添加日 K 序列与事件点，即可快速生成全新复盘剧本。

## 🚀 快速开始

### 方式一：直接浏览器打开
直接双击根目录下的 `index.html`，即可在浏览器中体验完整功能。

### 方式二：本地轻量服务启动（推荐）
如果浏览器因本地文件协议（`file://`）限制加载本地 JSON 数据，可使用以下任意命令启动微型服务：

```bash
# 使用 Node.js 自带脚本
node serve.js

# 或者使用 Python
python3 -m http.server 8080

# 或者使用 npx
npx serve .
```

打开浏览器访问 `http://localhost:8080` 即可。

### 方式三：GitHub Pages 在线访问
在 GitHub 仓库的 **Settings → Pages** 中，将 Source 选为 `Deploy from a branch`，Branch 选择 `main / (root)` 保存，几分钟后即可获得公网在线访问链接。
